# 职业证照续期采集服务

用于职业证照续期的本地数据采集与归档服务。当前版本从仓库自带的合成批次读取多门户页面，规整后写入进程内目录，并产出面向提醒服务的会员视图；来源内容和规整后的记录保留独立边界，便于在不访问外部系统的情况下复现采集过程。

## 数据模型

续期高峰季各会员门户的页面形态不一致，统一规整为两类记录，均携带 `memberId`、`applicationId` 和审核回合 `round`：

- **仅总状态页**：只有申请整体状态，产出 `application` 记录；
- **逐份明细页**：列出每份材料的审核意见，每份材料产出 `material` 记录（含审核意见 `comment`）。

页面级语义：

- **失败页**（带 `error`）只登记到 `failures`，不触碰既有记录——抓取失败不代表材料被删除；单页畸形同理，不中断整批；
- **取舍规则**：同一记录身份先比 `round` 再比 `revision`，会员重传后晚到的旧回合审核页不会覆盖新状态；
- **提醒视图**（`buildReminders`）按 会员 → 申请 聚合：已补齐的材料不再列为缺件；申请进入终态（`approved` / `rejected` / `withdrawn`）且回合不旧于材料记录时清除旧缺件；材料明细落后于申请最新回合时标记 `stale`。通知只消费这份视图，同一会员不会收到相互矛盾的通知。

## 运行

需要 Node.js 20 或更高版本，不需要安装第三方依赖。

```sh
npm test
npm run build
node src/pipeline.mjs
```

测试使用项目内的合成记录；执行不需要网络、凭据或外部服务。
